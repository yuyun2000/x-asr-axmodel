让 HTTPS 不再报警告

麦克风必须在 HTTPS 页面才能用。当前用的是本机自签证书，浏览器第一次会提示 "您的连接不是私密连接"，点「高级 → 继续前往」就能用； 把下面的 CA 证书装进系统并信任之后，就不会再提示。

第 0 步：下载 CA 证书

文件名 x-asr-local-ca.crt，有效期 10 年，只用于这台板子的 HTTPS。

下载 CA 证书 打开 HTTPS 页面

macOS / Chrome

  1. 下载 CA 证书，双击 → 钥匙串"系统"→ 添加
  2. 在钥匙串里找到 X-ASR Local CA → 双击 → 信任 → 使用此证书时选「始终信任」
  3. 或者一条命令（会提示输入密码）： 
    sudo security add-trusted-cert -d -r trustRoot \
  -k /Library/Keychains/System.keychain ~/Downloads/x-asr-local-ca.crt

iPhone / iPad（Safari）

  1. 用 Safari 打开本页 → 下载 CA
  2. 设置 → 通用 → VPN与设备管理 → 安装该描述文件
  3. 设置 → 通用 → 关于本机 → 证书信任设置 → 打开 X-ASR Local CA 的开关

Android / Chrome

  1. 下载 CA（.crt）
  2. 设置 → 安全 → 加密与凭据 → 安装证书 → CA 证书
  3. Chrome 重启后生效

Windows（Chrome / Edge）

  1. 双击 .crt → 安装证书 → 本地计算机 → 放入「受信任的根证书颁发机构」

不想安装证书也可以：直接打开 HTTPS 页面，点「高级 → 继续前往 192.168.10.144（不安全）」， 页面和麦克风都能正常用，只是每次浏览器重启会再提示一次。
